# Employee Attendance Management

A simple, responsive front-end UI for tracking employee attendance. This project provides a minimal HTML/CSS prototype for listing daily attendance, filtering by date/department, and showing a summary sidebar.

## Features
- Responsive table view of attendance records
- Date picker, search, and department filter controls
- Summary panel with totals and recent activity
- Lightweight: single HTML file with embedded CSS and minimal JS

## Tech
- HTML5
- CSS (plain)
- Vanilla JavaScript (trace initializer only)

## Demo / Preview
Open `index.html` in a browser to view the UI.

Quick preview on Windows (PowerShell):
1. Open the project folder in PowerShell:
   cd "C:\Users\aathi\OneDrive\Desktop\dhiyanesh java"
2. Start a simple server with Python (if installed):
   python -m http.server 5500
3. Open http://localhost:5500/index.html in your browser

Or use VS Code Live Server extension to preview.

## Getting started
1. Clone or copy the project into a local folder.
2. Open the folder in your editor (e.g., Visual Studio Code).
3. Edit `index.html` to add or modify attendance records and styles.

## Development notes
- The UI is static; persistence and backend APIs are not included.
- Add a backend (Node, Java, Python, etc.) if you need storage, authentication, or CSV export.
- Consider converting the table data into a JSON-driven render for easier testing and interactivity.

- Feel free to open issues or submit pull requests to improve layout, accessibility, or add features (filtering, export, backend integration).
